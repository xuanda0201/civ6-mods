# 杨广·通济四海 · Yang Guang: Four Seas

**独立新领袖 Mod，预览版 0.1.0。** 新增 `LEADER_XGYG`，与原来的 Phantagonist 杨广同时存在。原杨广的能力、人口瞬建机制、单位、仓廪和选人条目均不修改。新增领袖沿用原 Mod 的画像资源；五牙战舰第一版使用游戏现成护卫舰模型、图标，并非新制作的楼船 3D 模型。

## 必需内容与安装

要求《风云变幻》规则集，主要适配 HD v2.2 单机。必须同时启用：

- [Phantagonist：隋炀帝杨广](https://steamcommunity.com/sharedfiles/filedetails/?id=3595246973)
- [Phantagonist：中国王朝特性](https://steamcommunity.com/sharedfiles/filedetails/?id=3310033009)及其必需 DLC/依赖
- [和而不同](https://steamcommunity.com/sharedfiles/filedetails/?id=2465378070)
- 官方“撒哈拉统治者”DLC（哈庇的降临来源）

退出游戏，将 `dist/YangGuangRework-0.1.0.zip` 内的 `YangGuangRework` 文件夹放到 `文档\My Games\Sid Meier's Civilization VI\Mods`，启用本 Mod 及上述前置，再开单机新局，选择中国领袖 **“杨广·通济四海”**。不要选择原来的杨广来验证新能力，不要覆盖或删除工坊原文件。本包只有新增代码与引用定义，不附带原 Mod 的画像或单位资产。

已有原杨广存档不会变成新领袖；需新开一局。依赖未齐时请先解决前置缺失；SQL 会检查所需领袖、特性和护卫舰定义。

## 最终能力

### 通济四海

- 首都 +2 人口及免费粮仓；保留大举迁都项目（最多两次）。
- 工程科技解锁运河、堤坝；运河和奇观正常施工，不通过消耗人口瞬间完成。
- 保留隋朝“运河大业”：国内商路基础收益、水利目的地收益、运河提供的商路容量和免费商人，均引用当前王朝 Mod 规则。
- 获得秦国“法家改革”的军营、水利区域建设加成、建成赠建造者与文化炸弹；获得秦长城。解锁运河/堤坝的秦国重复条目不再额外加入。
- 获得实际安装 HD 版本的“中统建元”和“哈庇的降临”。通过分配相同来源 Trait 接入 HD 的现有规则与事件，不重新硬编码一份原版能力；各 HD 版本仍需实测。没有加入元朝文明整套特色或埃及文明能力。
- **四方通衢**：外国文明通往本方城市的国际商路，为目的城市提供 +2 金币、+1 文化；陆路、海路、混合路线均适用，每条只计一次，使用原生商路收益修正器。
- 不加入横扫六合、客卿、秦锐士，不具备仓廪建造资格。

### 中世纪特色单位

- **府兵**：保留原王朝 Mod 的设定，包括其劳动力与水利施工能力。移除的是人口换施工，不是府兵本身的劳动力能力；仓廪仍需对应特色资格，本领袖不授予。
- **骁果**：保留原杨广 Mod 的设定。
- **五牙战舰**：新增海军远程单位，替代护卫舰，雇佣兵市政解锁。基础战斗数值、移动力、造价、维护费、战略资源费用与升级目标从当前已加载的护卫舰复制。资源科技尚未满足时依然需要先满足资源要求；不是免费提前获得海军。
- **楼船水师**：在海岸地形，或己方已建成运河两格以内，+5 战斗力。两个条件和多条运河不叠加。
- **护航朝贡**：四格以内的己方商人免遭劫掠；多艘五牙不会把同种护航效果叠加。移动、战舰死亡、读档或回合切换时重算，离开范围撤销本 Mod 的护航能力，不动其他 Mod 的商人保护。

强势期侧重中世纪水利、贸易和水师；经济能力仍可从前期逐步发展，不将全部领袖能力锁定到中世纪才生效。

## 实现与验证

游戏数据和选人配置都使用独立领袖 ID，只向新领袖分配能力；原有领袖数据库行不做 UPDATE 或 DELETE。人口瞬建的上游脚本在初始化时缓存拥有原始杨广 Trait 的玩家，新领袖不持有该 Trait，保留其非脚本加成的修正器，因此不会进入两个扣人口分支。

本地已用你提供的原始杨广、隋朝及秦朝 SQL 建立临时数据库执行新 SQL，逐行检查旧数据保留、选人条目并存、府兵骁果资格、移除资格、建设修正器、五牙解锁与费用复制。加载实际原人口瞬建脚本验证原杨广仍匹配、新领袖不匹配。临时 Lua 模拟验证护航四格边界、两格己方已完工运河、海岸条件、死亡/移动撤销和不叠加。

**尚未实机验证。** 数据库模拟不是完整游戏数据库；画面、舰船模型/攻击动画、外交画像、实际商路收益、HD 中统建元事件、存档及升级链都需要 Windows 实测。没有添加测试框架或 CI。

最短试玩：确认两个杨广同时存在；新领袖放运河/奇观不扣人口，原杨广保持原机制；查看建设加成、府兵与骁果；用中世纪五牙测试近海战斗、护航进出范围、升级和资源费用；确认外国陆海商路收益。排错查看 `Database.log`、`Modding.log` 与 `Lua.log` 的 `[YangGuangRework]`。
