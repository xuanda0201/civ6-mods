# 杨广·通济四海

以运河连接城市，以水利支撑营建，以商贸汇聚四方。新增独立中国领袖“杨广·通济四海”，主特性统一为 **隋朝--通济四海**，搭配府兵、骁果和五牙战舰。

预览版 **0.1.3**，面向《风云变幻》与 HD v2.2 单机，尚未实机验证。原杨广保留，可分别选择。

## 隋朝--通济四海

- **营都兴业**：首都 +2 人口并获得免费粮仓；每建立一座新城市，获得一名建造者。可在拥有运河的城市开展“大举迁都”，最多两次。
- **开渠通漕**：工程科技解锁运河和堤坝。建造蓄水池（引水渠）、运河和堤坝时 +50% 生产力。建成运河另获 +1 商路容量和一名商人。
- **舟楫相望**：国内商路 +2 食物、+2 生产力、+2 金币，目的城市每座水利区域或仓廪再提供同等收益。外国通往本方城市的每条商路，为目的城市提供 +2 金币、+1 文化，陆海均适用。
- **泽润九州**：草原、平原、沙漠泛滥平原上的农场和种植园 +1 生产力；普通临河地块不包含。
- **万国来朝**：占领其他主要文明的原始首都时，获得该文明的特色能力。

水利建造加成、建城赠建造者及泛滥平原生产力均为本领袖独立设定。隋朝商路等继承效果仍读取已安装的前置定义。仓廪可作为既有商路目的地收益来源，本领袖不授予其建造资格。

## 特色单位

**府兵、骁果**沿用前置 Mod 的单位能力。府兵保留劳动力和水利施工能力。

**五牙战舰**是中世纪特色海军远程单位，取代护卫舰，雇佣兵市政解锁。位于海岸地形或己方已建成运河两格内时 +5 战斗力，条件不叠加；四格内的己方商人免遭劫掠，多艘战舰不叠加保护。

五牙的基础数值、费用、战略资源需求和升级目标读取当前护卫舰；仍须满足资源要求。预览版使用现成护卫舰模型与图标，领袖沿用原杨广画像。

## 安装

先安装并启用以下前置及其依赖：

- [Phantagonist：隋炀帝杨广](https://steamcommunity.com/sharedfiles/filedetails/?id=3595246973)
- [Phantagonist：中国王朝特性](https://steamcommunity.com/sharedfiles/filedetails/?id=3310033009)
- [和而不同](https://steamcommunity.com/sharedfiles/filedetails/?id=2465378070)
- 官方《风云变幻》，以及上述前置自身要求的 DLC

退出游戏，将 `dist/YangGuangRework-0.1.3.zip` 中的 `YangGuangRework` 文件夹复制到 `文档\My Games\Sid Meier's Civilization VI\Mods`。更新时替换本 Mod 的同名文件夹，前置文件保留。启用后开单机新局，选择“杨广·通济四海”；已有原杨广存档不会转换。本 Mod 已移除对原哈庇能力的引用，不再额外声明“撒哈拉统治者”DLC 依赖；前置 Mod 自身的要求仍须满足。

## 与原杨广的区别

新领袖取消消耗人口瞬建运河、奇观，不授予仓廪和秦长城；不含横扫六合、客卿、秦锐士。原杨广的能力、特色内容及选人条目不修改。

0.1.3 将营建加成限定为三类水利区域，取消区域完工赠建造者，改为每建立一座新城市赠一名建造者；泛滥平原能力改为指定改良 +1 生产力，替换旧文化、魅力及成长加成。军营不再获得营建或建造者奖励，区域文化炸弹仍取消。五牙战舰、府兵、骁果及其他能力保持原样。

## 验证与兼容

数据库检查覆盖新旧领袖并存、原数据保留及本轮能力变更：三类水利 +50%、军营和旧秦建造者触发器移除、旧哈庇修正器移除，以及三种泛滥平原与农场/种植园的组合条件。与 0.1.2 对比确认，其他主特性修正器和五牙战舰数据不变。

免费建造者只监听原生建城事件，为新领袖自己建立的城市发放，包括首都；占领、收回、完成区域或读档均不补发。一个城市标记和原生一次性奖励防止同一建城事件重复发放，无需维护城址记录或区域完成状态。

临时 Lua 模拟覆盖建城赠建造者的上述边界、护航范围与撤销，以及 HD 征服能力识别。原扣人口脚本也已验证只匹配原杨广。上述检查不等于实际游戏验证。

主特性合并已安装的来源修正器；HD 的 `Utils.LeaderHasTrait` 可通过玩家的 `TRAIT_LEADER_KUBLAI_CAPTURED` 标记识别征服能力，因此无需额外挂载显示为“中统建元”的来源特性。此标记只设置在新领袖玩家上，不修改 HD 或其他领袖。

尚需 Windows 实测模型动画、外交画像、商路收益、HD 事件、存档和升级链。排错请查看 `Database.log`、`Modding.log`、`Lua.log`，脚本输出前缀为 `[YangGuangRework]`。
