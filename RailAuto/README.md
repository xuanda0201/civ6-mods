# 沿途自动铺铁路 · Rail Auto

单机预览版 0.1.1。选中军事工程师、大亨等当前数据库允许铺铁路的单位，在右下角标准单位操作栏点击道路图标开启沿途铺铁路（高亮表示开启，再次点击关闭，悬停查看状态），然后正常右键移动。每个单位的开关独立，随存档保存。

按钮采用与移动、跳过相同的 44×53 底图和 38×38 图标。0.1.1 同时修正保存失败提示：只在对应单位上显示，切换单位不会串用。

## 安装

退出游戏，解压 `dist/RailAuto-0.1.1.zip`，复制其中的 `RailAuto` 文件夹到 `文档\My Games\Sid Meier's Civilization VI\Mods`。应为 `Mods\RailAuto\RailAuto.modinfo`，不要复制整个项目。在额外内容中启用，首次请开《风云变幻》单机新局。旧存档后加脚本能否正确加载尚未验证。

## 行为

- 开启时先检查当前所在地；随后由 Gameplay 的实际移动事件逐格检查，终点也施工。不拦截右键，不接管移动队列，不规划城市铁路网。
- 单位能否下海、如何寻路均由游戏决定。海面、山脉、不可通行地块、自然奇观、城市中心和奇观地块跳过，登陆后继续。第一版仅在自己或无主领土施工；他人领土正常经过。
- 已有铁路直接跳过，不重复付费；被劫掠的已有铁路保留手动修复，不免费修复。
- 不改变改良、资源、地貌、区域、火车站或隧道。其他 Mod 已生成的铁路也跳过。
- 铁路单位资格读取 `Route_ValidBuildUnits`，兼顾 `UnitReplaces` 替代链，支持按该表声明的大亨及其他单位，不给普通建造者凭空增加铁路能力。
- 科技与建造次数要求读取 `Routes_XP2`；科技未解锁时保留开关等待。如果当前规则铺铁路要消耗建造次数，停止自动施工并提示手动处理，不绕过次数要求。
- 资源按当前 `Route_ResourceCosts.BuildWithUnitCost` 基础费用扣除，不写死一铁一煤；逐格检查，资源不足时关闭施工，**正常移动继续**。补充资源后选中单位点击恢复；已走过的缺口不自动补铺。
- 关闭开关只停止施工，不取消玩家原有移动指令。正常手动移动不会像 BuilderAuto 那样关闭开关。

## 与手动施工的区别

这是跟随移动事件的沿途铺设模式，通过 `RouteBuilder.SetRouteType` 放置铁路，**不额外消耗施工行动力**。不是自动点击原生「修建铁路」操作。它读取数据库基础资源费用，不承诺识别其他 Mod 的额外脚本收费或费用修正器，也不手动补算原生施工的碳排放、时代得分等附加事件。这些效果是否被游戏自身触发尚未实测。

## 版本与兼容性

- **要求《风云变幻》规则集**；标准和《迭起兴衰》规则集不加载脚本和按钮。`.modinfo` 使用规则集条件，运行时再检查铁路数据表。
- 和而不同以用户当前合集条目 **HD v2.2** 为主要适配目标；读取实际安装的数据库，不按版本号硬编码费用，不替换 HD 单位面板。
- HD v2.2、其他 HD 版本、原版《风云变幻》及真实游戏的逐格移动事件、按钮布局、存档都**尚未实机验证**。其他 Mod 特有的铁路建造限制无法仅凭基础数据库完整判断。
- 不支持联机/热座；不要同时为同一单位开启其他自动铺铁路 Mod。与 BuilderAuto 分别管理铁路单位和建造者。

## 最短验证

在实际 HD 组合里启用后，选择军事工程师，确认右下角按钮；开启并移动过几格普通陆地和已有铁路，检查沿途无遗漏及逐格资源扣除。再使用大亨独立开启，确认彼此不影响。检查海面不铺、登陆继续、正常改良不变、关闭后不再铺设、资源不足不会扣成负数，以及保存返回主菜单读档后开关保留。

本地完成 Lua/XML/清单检查及执行实际源码的临时模拟：延迟挂载、选择切换、军事工程师/大亨/替代单位、科技、基础费用变化、已有铁路、海面与登陆、地形和领土排除、资源不足、异常退款、重复事件与 UI 重载。没有真实文明 6 运行环境，模拟不能验证游戏 API、原生副作用或当前 HD 完整兼容性。

排查查看 `Logs/Lua.log` 的 `[RailAuto]` 和错误；加载问题另看 `Modding.log`。完整兼容记录见仓库根目录 `COMPATIBILITY.md`。
